# DESIGN SYSTEM RULES

## Palette
- Foundation: Warm Paper / Ivory (`#F5F3EF`), Deep Charcoal / Ink (`#121110`), Muted Grey (`#7E7A75`), Hairline borders (`rgba(18, 17, 16, 0.08)`).
- Restrained Accent: Warm Ochre / Terra (`#A35D39` or `#967D62`) used sparingly for micro-accents.
- Project visual worlds: Confined strictly within project compositions. The site shell remains monochromatic, warm, and sophisticated.

## Typography
- Primary Sans: Clean, architectural contemporary sans-serif (`DM Sans`, -0.015em tracking for headers, clean body metrics).
- Secondary Accent: Refined serif accent used only for deliberate editorial contrast.
- Hierarchy:
  - Controlled headlines (3rem to 5.5rem max on desktop, never 13vw behemoths).
  - Clean utility metadata (`0.65rem` - `0.72rem`, uppercase, 0.16em tracking).
  - Editorial body (`1rem` - `1.15rem`, relaxed 1.65 line height).
